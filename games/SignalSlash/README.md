---

## 1. 어떤 게임?

- 신경 터널 저편에서 **상태창(문제 창)**이 날아와 눈앞에 멈춰요.
- **5초 안에 정답을 소리 내어 말하면** 3D 로봇 검사가 상태창을 단칼에 베어요.
- 마이크가 없으면 키보드 **1~4** 키나 보기를 눌러서 답해도 돼요.
- 빨리 말할수록 점수가 크고, 연속 정답이면 콤보가 쌓여요. 목숨은 5개예요.
- 구역 8개 + 랜덤 믹스, 신경해부학 **67문제**
  - 축삭 · 척수 반사 · 오름신경로 · 내림신경로 · 뇌줄기 · 뇌신경 · 대뇌 · 병변 진단(보스)
- 캐릭터: 로봇 **オーガロン(오가론)**, 만든 사람 Vain (VRoid Hub, 사용·수정·재배포 허용). 자세한 건 `models/README.md`에 있어요.

> 참고: 예전에 만든 "발진 → 비행" 판(최종본)이 아니라, **서서 문제만 맞히는 판**이에요.
> 비행판과 시그널 다이브는 `signal-dive` 갈래(branch)에만 있고 사이트에는 없어요.

## 3. 자주 고칠 것 — 어디를 바꾸면 되나

> 줄 번호는 2026-11-25 기준이에요. 고치다 보면 밀릴 수 있으니 **검색(Ctrl+F)으로 이름을 찾으세요.**

### 🎨 배경 (바뀔 수 있다고 한 부분)
배경은 사진이 아니라 `game.js`가 3D로 그려요. `/* ── 무대` 부분(65~136줄쯤)이에요.

| 바꾸고 싶은 것 | 찾을 이름 | 설명 |
|---|---|---|
| 하늘(바탕) 색 | `scene.background` | `0x05030f` = 거의 검은 남색 |
| 안개 색 · 진하기 | `scene.fog = new THREE.FogExp2(색, 진하기)` | 진하기를 올리면 멀리가 더 빨리 흐려져요 |
| 바닥 · 가운데 길 색 | `const floor`, `const lane` | `color: 0x07051a`, `0x120c34` |
| 날아오는 육각 문 | `const NR = 10, RSP = 20, RING_R = 7` | 개수 · 간격 · 크기 |
| 옆 기둥 | `const PIL_N = 22, PIL_SP = 12` | 개수 · 간격 |
| 바닥 줄무늬 | `const MARK_N = 30, MARK_SP = 8` | 개수 · 간격 |
| 하늘 레이저 | `// sky lasers` 아래 | 박자에 맞춰 움직이는 빛줄기 |
| 스쳐 가는 빛줄기 | `const NS = 160` | 개수. 0 이면 없어져요 |
| 길 끝 빛 | `const glow` | 터널 끝 동그란 빛 |
| 빛 번짐(블룸) | `new UnrealBloomPass(..., 0.9, 0.55, 0.82)` | 첫 숫자(세기)를 낮추면 덜 번져요 |

- 문 · 기둥 · 레이저 색은 **구역마다 자동으로 바뀌어요.** 구역 색은 `stages.js`의 `color`예요.
- 색을 바꾸는 코드는 `game.js`의 `ringMat.color.set(c)` 줄(650줄쯤)이에요.
- **사진 배경으로 바꾸고 싶다면** 두 가지 방법이 있어요.
  - `scene.background = new THREE.TextureLoader().load('img/배경.jpg')` 처럼 바꾸기
  - `index.html`의 `#gl` 캔버스 뒤에 CSS 배경을 깔고, `renderer`를 투명(`alpha: true`)으로 하기

### 🪟 상태창 (문제 창)
| 바꾸고 싶은 것 | 찾을 이름 |
|---|---|
| 창이 멈추는 위치 | `const WIN_POS = new THREE.Vector3(0.75, 2.1, -6.2)` — (오른쪽+, 위+, 거리) |
| 창 크기 | `const CW = 1024, CH = 640, W = 11, H = 6.875` — `W`·`H`만 같은 비율로 |
| 보기 4칸 위치 · 크기 | `const OPT_W`, `const OPT_BOX` — 왼쪽 칸은 로봇에 안 가리게 오른쪽으로 모아 둠 |
| 창 안 글자 · 색 · 모양 | `function drawPanel` |
| 베는 효과 | `function cutWindow` |

### 🤖 로봇 (검사)
| 바꾸고 싶은 것 | 찾을 이름 |
|---|---|
| 캐릭터 파일 · 위치 · 크기 · 방향 | `const HERO3D = { file, pos, scale, turn }` |
| 자세 (기본 · 칼 들기 · 베기 · 맞음) | `const POSES = { idle, ready, strike, hurt }` |
| 칼 색 · 칼 방향 | `const bladeMat`, `const BLADE` |
| 조명 | `const keyLight`, `const rimLight` |

- 다른 캐릭터로 바꾸려면 `.vrm` 파일을 `models/`에 넣고 `HERO3D.file`만 바꾸면 돼요. 아래 **🧍 캐릭터 바꾸기**를 보세요.
- **이용 조건(수정·재배포 허용)을 꼭 확인**하고 `models/README.md`에 적어 주세요.

### 🧍 캐릭터 바꾸기 — 받는 곳과 넣는 법

이 게임은 **VRM** 파일(`.vrm`, 사람 모양 3D 캐릭터 형식)이면 어떤 캐릭터든 쓸 수 있어요.
VRoid로 만든 캐릭터는 뼈 이름이 같아서 자세(`POSES`)가 그대로 맞아요.

#### ① 바로 쓸 수 있는 캐릭터 (이미 받아 둔 것)
| 캐릭터 | 파일 | 어디 있나 | 이용 조건 |
|---|---|---|---|
| 로봇 오가론 (지금 캐릭터) | `ogreron.vrm` (10MB) | 이 폴더 `models/` | Vain · 사용·폭력·수정·재배포 허용 |
| **여고생 '센다가야 시부'** (예전 캐릭터) | `shibu.vrm` (17MB) | GitHub `signal-dive` 갈래의 `games/SignalSlash/models/shibu.vrm` | VRoid 공식 샘플 · **CC0** (아무 조건 없음) |

여고생으로 되돌리는 법:
1. `signal-dive` 갈래에서 `shibu.vrm`을 이 폴더의 `models/`로 복사해요.
   - GitHub 웹에서: 저장소 → 갈래를 `signal-dive`로 → `games/SignalSlash/models/shibu.vrm` → Download
   - 명령어로: `git show signal-dive:games/SignalSlash/models/shibu.vrm > games/SignalSlash/models/shibu.vrm`
2. `game.js` 맨 위 줄을 이렇게 바꿔요. 예전에 쓰던 값이에요.
   ```js
   const HERO3D = { file: 'models/shibu.vrm', pos: [-1.42, -0.05, 1.65], scale: 1, turn: 0.18 };
   ```
3. 로봇은 몸집이 커서 `scale: 0.85`였어요. 사람 캐릭터는 `scale: 1` 정도면 맞아요.

#### ② 새 캐릭터를 받는 곳
| 곳 | 주소 | 특징 |
|---|---|---|
| **VRoid Hub** | https://hub.vroid.com | 캐릭터가 제일 많아요. 무료 가입·로그인 필요. 작가가 **"다운로드 허용"**을 켠 캐릭터만 받을 수 있어요 |
| **OpenGameArt (VRoid CC0 샘플)** | https://opengameart.org/content/vroid-studio-cc0-models | VRoid 공식 샘플 캐릭터 모음 (시부도 여기서 받았어요). 조건 없음 |
| **VRoid Studio** | https://vroid.com/studio | 무료 프로그램. **우리만의 캐릭터를 직접 만들어** `.vrm`으로 내보낼 수 있어요. 저작권 걱정이 제일 적어요 |

#### ③ VRoid Hub에서 받을 때 꼭 볼 것 (이용 조건)
캐릭터 페이지의 **"이용 조건"**을 열어서 아래를 확인하세요.
- **아바타 사용**: 허용 (또는 "누구나")
- **폭력 표현**: 허용 ← 칼로 베는 게임이라 필요해요
- **수정(개변)**: 허용 ← 자세를 바꾸고 칼을 쥐여 주니까 필요해요
- **재배포**: 허용 ← 사이트에 파일을 올리니까 **꼭** 필요해요
- **상업 이용**: 동아리·공모전용이면 "비영리 허용"이면 돼요. 상금이 있는 공모전이면 "허용"인 게 안전해요
- **하나라도 "불가"면 쓰지 마세요.**

#### ④ 넣는 법
1. 받은 `.vrm` 파일을 `games/SignalSlash/models/`에 넣어요. 파일 이름은 영어로 짓는 게 좋아요 (예: `mychar.vrm`).
2. `game.js` 맨 위 `HERO3D`에서 `file: 'models/mychar.vrm'`으로 바꿔요.
3. 화면에서 위치가 어색하면 숫자를 조금씩 바꿔 보세요.
   - `pos: [왼쪽(-)/오른쪽(+), 아래(-)/위(+), 앞(-)/뒤(+)]`
   - `scale`: 크기
   - `turn`: 몸을 돌리는 각도
4. `models/README.md`에 **캐릭터 이름 · 만든 사람 · 받은 주소 · 이용 조건 · 받은 날짜**를 적어요.
5. 파일이 크면(20MB 넘게) 폰에서 늦게 떠요. 가능하면 가벼운 캐릭터를 고르세요.

> 3D 파일을 못 불러오면 게임이 자동으로 `img/pose-*.webp` 사진으로 바뀌어요. 이 사진은 예전 사람 검사예요.

### ⏱ 규칙 · 소리
| 바꾸고 싶은 것 | 찾을 이름 (game.js 맨 위) |
|---|---|
| 한 문제 제한 시간 | `const TIME = 5` |
| 목숨 수 | `const LIVES = 5` |
| 랜덤 믹스 문제 수 | `const MIX_COUNT = 15` |
| 기본 음악 빠르기 | `const BPM = 140` |
| 효과음 | `const SFX = {` |

- 시작 화면의 **🎵 내 음악 넣기** 버튼으로 각자 음악 파일을 넣어 플레이할 수도 있어요. 사이트에는 안 올라가요.

### 📝 문제 고치기 (`stages.js`)
```js
{ q: '질문', a: '정답', w: ['오답1', '오답2', '오답3'], e: '맞힌 뒤 보여 줄 짧은 해설' },
```
- 구역 하나 = `{ id, no, title, sub, color, intro, qs: [문제들] }`
- 보기는 정답 1 + 오답 3을 섞어서 보여 줘요.
- **의학용어는 대한의사협회 6판 신용어**로 써 주세요.
- 말로 답하는 게임이라 정답은 **소리 내서 읽기 쉬운 말**이 좋아요. 너무 길면 인식이 잘 안 돼요.

- 배너 뒤 전체 배경을 넣으려면 `bg: "thumbs/새그림.jpg"`를 추가하면 돼요.

## 4. 고친 뒤 올리기 전에 (꼭!)

1. `git fetch` 로 남이 올린 게 있는지 먼저 받기
2. 내 컴퓨터에서 열어 보기 (`삼공육 실행.bat` → 허브 → 시그널 슬래시)
   - 마이크는 `http://localhost`나 `https` 주소에서만 돼요.
   - 주소 끝에 `?mic`를 붙이면 음성 인식이 지금 뭘 듣는지 왼쪽 위에 보여요.
3. `sw.js` 맨 위 `CACHE` 숫자를 하나 올리기. 안 올리면 폰에 옛날 버전이 남아요.
4. 내가 바꾼 파일만 `git add` → 커밋 → push (`--force` 금지)
5. 약 30초 뒤 사이트에서 바뀐 게 보이는지 확인

## 5. 이번에 한 일 (2026-11-25)
